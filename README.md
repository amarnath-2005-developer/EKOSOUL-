# 🌿 EKOSOUL – Emotion-Based Music Recommendation System

EKOSOUL is an AI-powered emotion recognition and music recommendation system that detects user emotions from text and audio inputs and recommends suitable playlists accordingly.

Built using Python, machine learning concepts, and emotion analysis techniques, EKOSOUL creates a personalized and emotionally adaptive music experience.

---

# 🚀 Features

- 🎙️ Audio Emotion Detection
- 💬 Text Emotion Analysis
- 🎵 Smart Playlist Recommendation
- 😊 Emotion-Based Song Suggestions
- 📂 JSON-Based Playlist Management
- ⚡ Fast and Lightweight Python Backend
- 🧠 AI-Powered Recommendation Logic

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/amarnath-2005-developer/EKOSOUL-.git
```

Move into the project directory:

```bash
cd EKOSOUL-
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

```bash
python app.py
```

# 🧠 How It Works

1. User provides text or audio input
2. Emotion detection module analyzes the mood
3. Recommendation engine selects suitable playlist
4. Personalized songs/playlists are suggested
